# RTMN Mini App

A mobile-first Telegram Mini App storefront built with React + Vite.

## Local setup

1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL shown by Vite.

## Production build

```bash
npm run build
```

The production files are generated in `dist/`.
